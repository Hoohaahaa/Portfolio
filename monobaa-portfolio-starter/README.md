# MONO. — Portfolio

Bilingual editorial portfolio built from the original spatial prototype.

## Run
Open `index.html` in a browser. The prototype is dependency-light and uses CDN-hosted GSAP / ScrollTrigger for motion.

## Experience
- Oversized MONO. hero typography and dark editorial grid.
- Three-card angled project deck with numbered navigation and touch swipe.
- Ten project entries, including separate Humaani / Arzhang and MaaniJect case studies.
- English / Persian language switch with RTL support.
- Project detail overlays, image galleries and click-to-zoom.
- Responsive layout and reduced-motion support.

## Project assets
See `assets/PROJECT-ASSET-ARCHIVE.md` and `assets/manifest.json` for the permanent asset structure and source mapping. Keep original exports unchanged in `assets/projects/<slug>/originals/`; place optimized WebP derivatives in `assets/projects/<slug>/web/`. Preserve aspect ratio and never mix Humaani / Arzhang with MaaniJect.

The current MaaniJect visual is explicitly marked as a temporary placeholder. The original MaaniJect screenshots have been identified (`humaani-1.png` and `mobile-1.png`) but the binary files are not yet present in this Git branch.
