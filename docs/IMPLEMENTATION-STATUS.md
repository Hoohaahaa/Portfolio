3. Open System and run Test model connection.
4. Submit a bounded non-confidential brief, with optional public search off for the first run.
5. Verify actual specialist outputs, provenance, checks and independent critique.
6. Reopen the run URL after closing the browser, then exercise the real review gate and exports.
